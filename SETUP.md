# SETUP.md

## Требования

### [k_board.py](https://github.com/KamalV10/Python-Workpieces/blob/main/k_board.py)

1. *Версия Python - не указано*
2. *Версия pip - не указано*
3. *Библиотека [keyboard](https://pypi.org/project/keyboard/)*
```pip install keyboard```

### [github_api.py](https://github.com/KamalV10/Python-Workpieces/blob/main/github_api.py)

1. Версия Python - от 3.10*
2. *Версия pip - от 2.34.2*
3. *Библиотека [requests](https://pypi.org/project/requests/) и зависимости (certfil, charset-normalizer, idna, urllib)*
```pip install requests```

### [game.py](https://github.com/KamalV10/Python-Workpieces/blob/main/game.py)

1. *Библиотека [pygame](https://pypi.org/project/pygame/)*
2. *Версия Python - от 3.0 до 3.12*
3. *Версия pip - от 2.6.1*
```pip install pygame```
