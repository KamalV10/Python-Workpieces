# README.en.md

## Description

This repository contains usage examples for various Python libraries (including PyPI libraries). All files can be customized to your needs if necessary.

## Ways to download the repository

1. Command line:
*Git is required*
*Convenient for editing*
*Downloads the latest version of the repository*
```git clone --depth 1 https://github.com/KamalV10/Python-Workpieces.git```
2. Also command line:
*Git is not required, but wget is needed*
*Downloads only the archive with all repository files* (including .gitignore and .gitattributes)
```wget -L https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip```
3. [Via link](https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip):
*Surprisingly, only a web browser is needed*

Additionally, in [SETUP.md](https://github.com/KamalV10/Python-Workpieces/blob/main/SETUP.md), I have outlined the requirements and notes (where applicable) for each file.
