# README.md

## Описание

Это примеры использования для разных библиотек Python (Включая PyPi библиотеки). Все файлы можно изменить под себя при надобности.

## Способы скачивания репозитория

1. Командная строка:
*требуется Git*
*удобно использовать для редактирования*
*скачивает последнюю версию репозитория*
```git clone --depth 1 https://github.com/KamalV10/Python-Workpieces.git```
2. Тоже командная строка:
*Git не требуется, но нужен wget*
*скачивается только архив со всеми файлами репозитория(включая .gitignore и .gitattributes)*
```wget -L https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip```
3. [По ссылке](https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip):
*как ни странно, нужен только браузер*

Также в [SETUP.md](https://github.com/KamalV10/Python-Workpieces/blob/main/SETUP.md) я написал требования и примечания (при надобности) к каждому файлу.
