Это примеры использования для разных библиотек Python (Включая PyPi библиотеки). Все файлы можно изменить под себя при надобности. Ниже будут описаны способы скачивания репозитория
1. Командная строка (требуется Git, удобно использовать для редактирования, скачивает весь репозиторий вместе с историей, можно прописать *--depth 1* между) "git clone", и ссылкой чтобы скачать только последнюю версию
```shell
git clone https://github.com/KamalV10/Python-Workpieces.git
```
2. Командная строка (тоже, Git не требуется, но нужен wget, скачивается только архив со всеми файлами репозитория) 
```shell
wget -L https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip
```
3. Через браузер (нужен только браузер как ни странно) https://github.com/KamalV10/Python-Workpieces/archive/refs/heads/main.zip

Также в [SETUP.md](https://github.com/KamalV10/Python-Workpieces/blob/main/SETUP.md) я написал требования и примечания (при надобности) к каждому файлу.
